# Como contribuir

## Branches

- Criar uma branch para cada alteração.
- Evitar alterações diretamente na `main`.

## Commits

- Utilizar mensagens claras que descrevam a alteração realizada.

## Pull Requests

- As alterações devem ser enviadas por Pull Request.
- Pelo menos um integrante da equipe deve revisar e aprovar antes do merge.

## Organização

As regras de contribuição poderão ser atualizadas conforme o projeto e o processo de desenvolvimento da equipe forem definidos.
