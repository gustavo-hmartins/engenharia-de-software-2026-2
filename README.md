# Carteira de Investimento

## Sobre o Projeto
Sistema desenvolvido como projeto acadêmico para a disciplina de Engenharia de Software, com o objetivo de auxiliar usuários no gerenciamento e acompanhamento de seus investimentos.

A aplicação permite organizar uma carteira de investimentos, acompanhar os ativos cadastrados e visualizar informações relevantes sobre a composição e o desempenho da carteira.

## Objetivo
O objetivo do projeto é desenvolver uma aplicação que facilite o gerenciamento de uma carteira de investimentos, permitindo que o usuário registre seus ativos e acompanhe informações relacionadas aos seus investimentos de forma organizada.
O projeto também tem como finalidade aplicar, na prática, conceitos estudados na disciplina de Engenharia de Software.

## Funcionalidades Planejadas
### Usuário
    - Cadastro de usuário;
    - Login e autenticação;
    - Perfil de investidor.

### Carteira
    - Criar uma carteira de investimento;
    - Adicionar ativos;
    - Remover ativos;
    - Editar informações dos ativos;
    - Visualizar composição da carteira;
    - Consultar o valor total investido.

### Acompanhamento
    - Visualizar desempenho da carteira;
    - Visualizar valorização ou desvalorização dos ativos.
